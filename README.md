# why are we here
I'm learning programming not to write code myself, but to gain the ability to evaluate whether AI-generated code is reliable. When an AI-produced 3D model is placed before me, I can tell it's wrong because I understand modeling; but if an AI gives me a piece of Python code, I can't even tell whether it's correct or not. This sense of helplessness is exactly why I'm sitting in this classroom.

I studied arts and crafts at the undergraduate level and specialized in champlevé enamel. My materials were copper and enamel. The process involved melting the enamel at a high temperature of 800°C and allowing it to adhere to the recesses in the copper. My graduation project was to create a set of copper-based enamel bird sculptures. I had already drawn the design sketches and wanted to convert them into 3D models. Someone recommended Tripo3D - an AI tool that can generate 3D models from images. I uploaded the design sketches. Unfortunately, the AI-generated model did not meet my expectations, and it was completely unusable. Eventually, I chose to model it myself in Nomad and made post-processing adjustments using the built-in tools: smoothing, carving, and hollowing out. The tools were sufficient, and I was able to create what I wanted.


But I asked myself a question: What if I wanted to make ten birds with different postures? What if I wanted to use a set of feather logic - where the texture and density of the feathers change automatically according to the curvature of the body - in a rule-based way?
Nomad couldn't do it. Its tools were hardcoded. I could drag vertices one by one, but I couldn't tell the software: "Design the feathers according to this formula." The tools I used were designed by others, and my creativity was limited by their pre-set assumptions about "what the tools should do".
I heard that Blender has a Python API - allowing you to define your own rules. But the problem was: I had no programming background. I couldn't judge whether "Python could solve my problem" or whether "spending several months learning programming was worth it".
