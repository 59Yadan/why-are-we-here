# why are we here
## The Thesis: Why I'm Here
I'm learning programming not to write code myself, but to gain the ability to evaluate whether AI-generated code is reliable. When an AI-produced 3D model is placed before me, I can tell it's wrong because I understand modeling; but if an AI gives me a piece of Python code, I can't even tell whether it's correct or not. This sense of helplessness is exactly why I'm sitting in this classroom.
## An experience of AI generation failure
I majored in arts and crafts at the undergraduate level and specialized in champlevé enamel. My materials were copper and enamel. The process involved melting the enamel at a high temperature of 800°C and allowing it to adhere to the recesses in the copper. My capstone project was to create a set of copper-based enamel bird sculptures. I had already drawn the design sketches and wanted to convert them into 3D models. Someone recommended Tripo3D - an AI tool that can generate 3D models from images. I uploaded the design sketches. Unfortunately, the AI-generated model did not meet my expectations, and it was completely unusable. Eventually, I chose to model it myself in Nomad Sculpt and made post-processing adjustments using the built-in tools: smoothing, carving, and hollowing out. The tools were sufficient, and I was able to create what I wanted.
## The Hardcoded Limit
But I asked myself a question: What if I wanted to make ten birds with different postures? What if I wanted to use a set of feather logic - where the texture and density of the feathers change automatically according to the curvature of the body - in a rule-based way?
Nomad Sculpt couldn't do it. Its tools were hardcoded. I could drag vertices one by one, but I couldn't tell the software: "Design the feathers according to this formula." The tools I used were designed by others, and my creativity was limited by their pre-set assumptions about "what the tools should do".
I heard that Blender has a Python API - allowing you to define your own rules. But the problem was: I had zero programming experience. I couldn't judge whether "Python could solve my problem" or whether "spending several months learning programming was worth it".
## The Judgment I Don't Have
Someone said: "Why bother learning by yourself? AI can even write code. You describe the requirements and it helps generate the script for you."
This sounds reasonable. But it doesn't work. Not because AI can't write code - it can. But I can't judge whether the code it generates is correct.
Even more alarmingly, under stricter evaluation, the error rate of AI-generated code is far higher than we imagined. A study published at NeurIPS 2023 found that after augmented testing, the pass rate of code generated by large language models dropped by 19.3% - 28.9%, much of the "seemingly correct" code actually contains undetected errors ([Liu et al., 2023](https://arxiv.org/abs/2305.01210)).
If we translate this problem into a domain I'm familiar with: An apprentice shows me what he has made. At first glance, it looks fine - but I can tell immediately that something is wrong. My eyes know what a good surface should look like, and my hands know how it should feel when touched. I can judge because I have done it myself, over and over.
But if AI gives me a Python script and says it can automatically carve the feather grooves, but I can't judge whether it is correct. Maybe it uses the wrong variable in the loop, maybe it calculates the depth wrongly,maybe the effect it generates looks good on the screen but would fail in the foundry - collapsing under heat or leaving no room for the enamel to flow. I have no ability to judge at all. The code might be written very well, but it doesn't meet my requirements.
## The Master's Eyes
Reading code and writing code are two different things. If you can't write it yourself, you don't have the qualification to judge whether the machine-generated code is good or not. I'm not here to become a programmer. I'm not here to compete with AI in writing code. I'm here to learn programming - not to outdo AI in writing, but to be able to understand what AI has written, and then have the confidence to say: Is this correct or incorrect, and why.
This is completely a different kind of ability: the ability of a critic, the ability of an editor, the ability of a master who can spot where an apprentice has gone wrong. The AI is that fast-moving, never-tiring apprentice. But someone still has to be the master.
