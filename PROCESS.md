# How I used AI
## Tools i have used
I used Deepseek throughout the process. I used it for:
- **Brainstorming** — exploring different angles on the essay question and discussing how my personal experience might fit the assignment's prompts.
- **Structuring** — organising my thoughts into a clear argument flow.
- **Format** — I used AI to enhance my formatting.
## What I kept
I kept the structure that AI suggested: **open with a one-sentence thesis → transition to my personal experience → return to the thesis at the end.**
Specifically, it helped me map out this line:

1. **The opening sentence states the core argument**: "I'm learning programming not to write code myself, but to gain the ability to evaluate whether AI-generated code is reliable."
2. **The middle uses my real experience to prove it**: Tripo3D failed to generate usable feather grooves → Nomad's built-in tools are hardcoded → I cannot read a Python script, so I cannot judge whether it is correct.
3. **The ending returns to the thesis**: "The AI is that fast-moving, never-tiring apprentice. But someone still has to be the master."

This structure works because it gives the essay a clear skeleton — state a position, support it with concrete facts, then come back to it. AI suggested this "thesis → example → return" framework early in the brainstorming phase, and I kept it because it turned what could have been a rambling personal reflection into a focused argument.
## What I rejected
First, it proposed that I learn programming in order to "batch-process repetitive tasks in Nomad." I rejected this because Nomad has no scripting interface.

Second, The AI generated a paragraph that said something like:
 "In an era of rapid technological change, we must embrace new tools while staying true to our artistic vision. The fusion of traditional craftsmanship and artificial intelligence opens up unprecedented creative possibilities." I rejected this completely, because i feel it's somewhat off-topic for the paper.
## Honest note
I have zero programming experience. I used AI heavily in this assignment. But every argument in the essay is mine — tested against my actual experience, filtered through my own judgment, and rewritten until it sounded like me.
